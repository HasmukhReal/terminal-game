# Terminal Games

A collection of games designed to be played in the terminal.

## Games

### 1. Guess the Number (C)
A classic game where you try to guess a random number between 1 and 100.

**How to run:**
1. Navigate to the `games/` directory.
2. Compile the game using a C compiler (like `gcc`):
   ```bash
   gcc guess_the_number.c -o guess_the_number
   ```
3. Run the executable:
   - On Windows: `.\guess_the_number.exe`
   - On Linux/Mac: `./guess_the_number`

## Getting Started

To play any of the games, ensure you have the necessary compilers/runtimes installed as listed in the game descriptions.
